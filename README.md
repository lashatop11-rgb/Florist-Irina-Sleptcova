# Сайт + бот «В наличии»

Ирина отправляет боту фото с подписью, бот спрашивает: **💐 Готовый букет** или **🌷 Свежая поставка**.
Букет попадает в блок «Готовые букеты», цветок — в «Свежую поставку». Пустые блоки на сайте скрыты.

## Файлы
- `index.html` — сайт
- `api/telegram.js` — бот (вебхук)
- `api/items.js` — список букетов для сайта
- `api/photo.js` — фото букетов (берутся из Telegram)
- `api/setup.js` — одноразовое подключение бота
- `package.json` — нужен Vercel, не удалять

## Подключение (один раз, ~10 минут)
1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. **База.** Vercel → проект → вкладка **Storage** → **Create Database** → **Upstash for Redis** (Free) → **Connect** к проекту.
3. **Переменные.** Vercel → проект → **Settings → Environment Variables**, добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `TELEGRAM_SECRET` — придуманный код, только латиница, цифры и `_`, например `roses_tuchkovo_2026`
4. **Загрузка через GitHub.** Откройте репозиторий сайта на github.com → **Add file → Upload files** →
   перетащите из этой папки `index.html`, `package.json`, `README.md` и **всю папку `api`** →
   **Commit changes**. Vercel сам выложит новую версию за 1–2 минуты (вкладка Deployments → статус Ready).
   Если переменные из шага 3 добавлены уже после загрузки — Deployments → ⋯ → **Redeploy**.
5. **Запуск бота.** Откройте в браузере:
   `https://florist-irina-sleptcova.vercel.app/api/setup?key=ВАШ_КОД`
   Должно появиться «Готово!».
6. **Доступ Ирине.** Ирина открывает своего бота и отправляет: `/admin ВАШ_КОД`.
   Посторонние люди публиковать не смогут.

## Как пользоваться (для Ирины)
- Фото + подпись → бот спросит, куда добавить.
  - 💐 Готовый букет — название и цена (обязательно): `Пионы с эвкалиптом, 4500`
  - 🌷 Свежая поставка — сорт и, если хотите, цена за штуку: `Пионы Сара Бернар, 350`
- Вторая строка подписи — описание (необязательно). Одно фото = один букет или один сорт.
- Подпись можно исправить в Telegram — сайт обновится.
- Под букетом: 🔒 Бронь, ✅ Продано, 🗑 Удалить. Под цветком: 🥀 Закончились.
- `/list` — что сейчас на сайте.

## Публикация в Telegram-канал
Всё, что публикуется на сайте, бот сам выкладывает в канал @FloristIrinaSleptsova — фото, название, цена
и кнопки «Забронировать», «WhatsApp», «Всё в наличии на сайте». Бронь / Продано / Закончились меняют пост
в канале (пометка, у проданного — зачёркнутая цена), 🗑 Удалить — удаляет пост.

Подключение: канал → **Управление каналом → Администраторы → Добавить администратора** → бот →
права «Публикация сообщений», «Редактирование», «Удаление сообщений» → Сохранить.
Затем боту: `/channel @FloristIrinaSleptsova` — он проверит права и ответит «Готово».
`/channel off` — публиковать только на сайт, `/channel` — какой канал подключён.
