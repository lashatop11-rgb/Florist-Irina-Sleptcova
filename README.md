# Сайт + бот мастерской «Флорист Ирина Слепцова»

Ирина управляет сайтом из Telegram-бота: публикует готовые букеты, свежую поставку и работы в портфолио
(сразу или по расписанию), получает заявки, брони и отзывы с сайта — с кнопками. Клиенты могут следить
за своей заявкой в том же боте, а бот помнит историю каждого клиента.

## Файлы
- `index.html` — сайт
- `privacy.html` — политика конфиденциальности (ссылка под формами)
- `og.jpg` — картинка для превью ссылки в мессенджерах
- `robots.txt`, `vercel.json` (запуски бота в 9:00 и 18:00 — напоминания, праздники, отложенные фото), `package.json` — не удалять
- `api/` — бот и сервер:
  - `telegram.js` — бот (вебхук), `request.js` — формы сайта, `items.js` — данные для сайта,
    `cron.js` — напоминания, праздники и отложенные публикации, `photo.js` — фото из Telegram,
    `setup.js` — подключение бота, `_lib.js`, `_shop.js` — общий код

## Подключение (один раз)
1. **Бот.** @BotFather → `/newbot` → скопируйте токен.
2. **База.** Vercel → проект → **Storage** → **Create Database** → **Upstash for Redis** (Free) → **Connect**.
3. **Переменные.** Vercel → **Settings → Environment Variables**:
   - `TELEGRAM_BOT_TOKEN` — токен из шага 1
   - `TELEGRAM_SECRET` — придуманный код, только латиница, цифры и `_`, например `roses_tuchkovo_2026`
   - `METRIKA_ID` — *необязательно*, номер счётчика Яндекс Метрики (см. ниже)
   - `CRON_SECRET` — *необязательно*, любой набор латиницы и цифр: защищает напоминания от чужих вызовов
4. **Загрузка через GitHub.** Репозиторий → **Add file → Upload files** → перетащите из этой папки
   все файлы **и всю папку `api`** → **Commit changes**. Vercel выложит версию за 1–2 минуты.
   Файлы из `api` должны оказаться именно в папке `api` репозитория, а не в корне.
   Если переменные добавлены после загрузки — Deployments → ⋯ → **Redeploy**.
5. **Запуск бота.** Откройте `https://florist-irina-sleptcova.vercel.app/api/setup?key=ВАШ_КОД` — «Готово!».
   Повторите этот шаг после каждого обновления бота: так обновляется меню команд
   (меню видят только админы — клиенты в боте видят только свои заявки).
6. **Доступ.** Ирина отправляет боту `/admin ВАШ_КОД`. Заявки с сайта приходят всем, кто это сделал.

## Как пользоваться (для Ирины)
**Фото → бот спрашивает, куда добавить:**
- 💐 Готовый букет — подпись «название, цена»: `Пионы с эвкалиптом, 4500`
- 🌷 Свежая поставка — сорт и, если хотите, цена за штуку: `Пионы Сара Бернар, 350`
- 🖼 В портфолио — подпись = название работы (можно без неё), затем раздел: букеты, в коробках, корзины,
  свадебные, траурные, новогодние. Альбом из нескольких фото добавляется целиком.

Под букетом: 🔒 Бронь, ✅ Продано, 🏷 Скидка (−10…30%, на сайте и в канале видна старая цена), 🗑 Удалить.
Под цветком: 🥀 Закончились. Подпись можно исправить в Telegram — сайт обновится.

**⏰ Опубликовать позже** — кнопка под вопросом «Куда добавить?»: сегодня / завтра в 9:00 или 18:00.
На сайте фото появится ровно в это время, пост в канале — в течение часа (так работает бесплатный Vercel).
Под запланированным: 🚀 Опубликовать сейчас · 🗑 Отменить.

**С сайта приходят в бот:**
- 🛍 заявка из конструктора — кнопки «Принять → Готов → Выдан», WhatsApp / Telegram клиента;
- 🔒 бронь готового букета — «Подтвердить бронь» (на сайте и в канале станет «Забронирован») или «Отказать»;
- 💬 отзыв — «Опубликовать» или «Удалить». На сайт без проверки ничего не попадает.

**Клиент следит за заявкой.** После заявки или брони на сайте есть кнопка «Следить в Telegram» — она открывает
этого бота. Дальше клиенту само приходит: «Принята», «Букет готов» (с адресом мастерской), «Выдан» (с просьбой
об отзыве), для брони — «Подтверждена» / «Не получилось». В заявке видно «📲 Следит в Telegram».
- «✉️ Написать клиенту» под заявкой → следующее фото или сообщение уйдёт клиенту (например, фото готового букета).
  `/cancel` — передумали.
- Что клиент пишет боту, приходит Ирине с кнопкой «Ответить».

**База клиентов** собирается сама по номеру телефона. В заявке: «🆕 Новый клиент» или
«⭐ Постоянный клиент: раньше 3 обращения», кнопка «👤 История» — все прошлые заказы и брони.

**Праздники.** За 2–3 недели до 14 февраля, 8 Марта, последнего звонка, 1 сентября, Дня учителя,
Дня матери и Нового года бот предлагает объявление вверху сайта — одной кнопкой. После праздника оно снимается само.

**Команды:**
- `/list` — что в наличии · `/orders` — открытые заявки · `/works` — портфолио
- `/client` — постоянные клиенты · `/client 89261234567` или `/client Анна` — история заказов
- `/reviews` — отзывы · `/review Анна: спасибо за букет!` — добавить отзыв самой (оценка в конце: `★★★★`)
- `/banner Принимаем предзаказы на 14 февраля` — полоса вверху сайта · `/banner off` — убрать
- `/pause до 5 октября` — «мастерская на паузе» · `/pause off` — снять
- `/stats` — продажи за неделю / месяц, заявки, отзывы
- `/channel` — Telegram-канал · `/channel off` — публиковать только на сайт
- `/reviewchannel` — отдельный канал для отзывов · `/reviewchannel off` — выключить

**Сам бот:** каждое утро (≈9:00 МСК) напоминает о букетах, которые висят на сайте 2+ дня
(скидка / продано / снять / оставить), предлагает объявления к праздникам, по понедельникам присылает итоги недели.
В 9:00 и 18:00 выкладывает отложенные фото в канал.

## Telegram-канал
Всё, что публикуется, бот сам выкладывает в канал @FloristIrinaSleptsova, а кнопки меняют пост и там.
Бот должен быть администратором канала с правами «Публикация», «Редактирование», «Удаление сообщений».
Проверка и подключение: `/channel @FloristIrinaSleptsova`.

## Канал для отзывов (необязательно)
1. Telegram → **Новый канал**, например «Отзывы · флорист Ирина Слепцова». Лучше **публичный**
   (ссылка вида t.me/имя) — тогда на сайте под отзывами появится кнопка «Все отзывы в Telegram».
2. Канал → **Управление каналом → Администраторы → Добавить администратора** → бот →
   права «Публикация», «Редактирование», «Удаление сообщений».
3. Боту: `/reviewchannel @имя_канала`. Или `/reviewchannel`, а потом перешлите боту любой пост из канала —
   так подключается и закрытый канал.
4. Бот предложит выложить уже одобренные отзывы. Дальше каждый опубликованный отзыв сам появляется
   в канале, а «Скрыть» и «Удалить» убирают его и оттуда.

## Яндекс Метрика (необязательно)
1. metrika.yandex.ru → **Добавить счётчик** → адрес сайта → скопируйте номер счётчика.
2. Vercel → переменная `METRIKA_ID` = номер → **Redeploy**. Код на сайте менять не нужно.
3. Цели (Метрика → Цели → «JavaScript-событие»), идентификаторы:
   `order_site`, `reserve`, `review`, `whatsapp`, `telegram`, `call`, `route`, `map`.

## Если поменяется домен
Всё продолжит работать. Превью ссылок (`og.jpg`) берётся с адреса vercel.app — он остаётся рабочим.
